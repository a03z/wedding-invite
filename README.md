# Свадебное приглашение!

Сайт в стиле оборванного тетрадного листа: приглашение, список комнатных растений с примерными ценами по Вологде и опросник для гостей. Сайт хостится на GitHub Pages, ответы гостей сохраняются в Google Таблицу через Apps Script.

## Запуск

`public/` — статика, сервер не нужен. Для локальной проверки:

```powershell
npx -y serve public
```

Сайт: http://localhost:3000

## Деплой на GitHub Pages

1. Запушьте репозиторий на GitHub (ветка `main`).
2. Настройки репозитория → Pages → Build and deployment → Source: **GitHub Actions**.
3. Каждый пуш в `main` публикуется воркфлоу `.github/workflows/deploy.yml` — сайт появится по адресу `https://<логин>.github.io/<имя-репозитория>/`.

GitHub Pages отдаёт сайт по HTTPS.

## Ответы гостей

Бэкенда в проекте нет; ответы прилетают в Google Таблицу через Apps Script (см. `apps-script/Code.gs`):

1. Создайте пустую Google Таблицу.
2. В ней: Расширения → Apps Script, вставьте содержимое `apps-script/Code.gs` вместо стандартного файла.
3. Развернуть → Новое развёртывание → тип «Веб-приложение»: «Выполнять от моего имени», доступ — «Все, у кого есть ссылка».
4. Скопируйте URL развёртывания (оканчивается на `/exec`) и вставьте его в константу `RSVP_URL` в начале `public/app.js`.

Всё, ответы гостей — на первом листе таблицы (колонки: дата, имя, напитки, guest_id). Таблица же заменяет выгрузку для Excel: Файл → Скачать → CSV. Если гость отправит форму повторно с того же браузера, его строка обновится, а не задвоится.

## Что заменить перед публикацией

- `public/index.html` — имена, дата и место (в начале файла есть комментарий). Там же список растений, цены и заметки про аллергены.
- `public/index.html` — фраза «до 15 июня 2027» в блоке опросника.
- `public/index.html` — `<title>` и `<meta name="description">`.

## Про растения и аллергию

Отметки «гипоаллергенно» учитывают сок и запах, а не пыльцу: комнатные растения практически не дают пыльцы в помещении. Это бытовая оценка, не медицинская рекомендация — при тяжёлой аллергии выбор лучше обсудить с врачом. Цены ориентировочные: магазины Вологды и маркетплейсы, 2026 год; зависят от размера растения и горшка.

## Фотографии растений

Файлы лежат в `public/plants/` (600×600 JPEG). Источники — Pexels (лицензия Pexels) и Wikimedia Commons; автор и лицензия каждой фотографии указаны в блоке «Фотографии и лицензии» в самом низу страницы, оттуда же ссылка на исходник. При замене картинки обновите подпись в этом блоке в `public/index.html`.
