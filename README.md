# Свадебное приглашение!

Сайт в стиле оборванного тетрадного листа: приглашение, список комнатных растений с примерными ценами по Вологде и опросник для гостей. Ответы сохраняются в Upstash Redis, смотреть их можно в админке.

## Запуск

Нужен Node.js 22 или 24. Локальный сервер повторяет маршруты Vercel: статика из `public/`, функции из `api/`.

```powershell
npm install
copy .env.example .env
npm start
```

В `.env` укажите `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` и `ADMIN_PASSWORD`. Без них страница открывается, а сохранение ответов и админка не работают.

Сайт: http://localhost:3000

- адрес админки: http://localhost:3000/admin
- логин: `admin`
- пароль: значение `ADMIN_PASSWORD`

## Что заменить перед публикацией

- `public/index.html` — имена, дата и место (в начале файла есть комментарий). Там же список растений, цены и заметки про аллергены.
- `public/index.html` — фраза «до 15 июня 2027» в блоке опросника.
- `public/index.html` — `<title>` и `<meta name="description">`.

## Ответы гостей

- `/admin` — таблица всех ответов и счётчики по напиткам.
- `/admin.csv` — выгрузка для Excel (разделитель `;`, UTF-8 с BOM).
- Записи лежат в Upstash Redis (ключи `rsvp:*`).
- Если гость отправит форму повторно с того же браузера и тем же именем, его ответ обновится, а не задвоится. Второй гость с того же устройства сохранится отдельной строкой.

## Про растения и аллергию

Отметки «гипоаллергенно» учитывают сок и запах, а не пыльцу: комнатные растения практически не дают пыльцы в помещении. Это бытовая оценка, не медицинская рекомендация — при тяжёлой аллергии выбор лучше обсудить с врачом. Цены ориентировочные: магазины Вологды и маркетплейсы, 2026 год; зависят от размера растения и горшка.

## Фотографии растений

Файлы лежат в `public/plants/` (600×600 JPEG). Источники — Pexels (лицензия Pexels) и Wikimedia Commons; автор и лицензия каждой фотографии указаны в блоке «Фотографии и лицензии» в самом низу страницы, оттуда же ссылка на исходник. При замене картинки обновите подпись в этом блоке в `public/index.html`.

## Публикация на Vercel

Импортируйте репозиторий в Vercel. Сборка не нужна: `public/` отдаётся как сайт, файлы в `api/` становятся функциями. В настройках проекта → Environment Variables задайте:

- `UPSTASH_REDIS_REST_URL` (или `KV_REST_API_URL`)
- `UPSTASH_REDIS_REST_TOKEN` (или `KV_REST_API_TOKEN`)
- `ADMIN_PASSWORD`

Базу Upstash можно создать в [Vercel Marketplace](https://vercel.com/marketplace/upstash) или в консоли Upstash: подойдут REST URL и токен. В `package.json` указан Node.js `22.x` или `24.x`, на Vercel выберется 24.

Сайт публикуйте только по HTTPS: пароль админки передаётся в заголовке Basic Auth и без HTTPS его можно перехватить.
